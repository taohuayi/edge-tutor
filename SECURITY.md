# Security policy

## Supported version

Security fixes are applied to the latest release on `main`.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential, or unsafe agent behavior. Contact the repository owner privately through the email address listed on the GitHub profile, with reproduction steps and impact. You should receive an acknowledgement within seven days.

## Sensitive data

Edge Tutor can read notes within the currently open Obsidian vault and can send configured context to the AI endpoint selected by the user. Review provider policies before enabling remote AI features. The optional OpenCode mode can use local file, shell, and network tools; it is opt-in and should be treated as a privileged local integration.
