# Contributing to Edge Tutor

Thank you for helping make learning with Obsidian more durable and inspectable.

## Before opening a pull request

1. Create a focused branch from `main`.
2. Install dependencies with `npm ci`.
3. Run `npm test` and `npm run build`.
4. Do not commit `data.json`, API keys, local model files, generated vector indexes, or `node_modules`.

## Good first contributions

- English localization of visible UI strings.
- A small demo vault and screenshots that contain no personal content.
- Accessibility, keyboard-navigation, and theme compatibility improvements.
- Tests for parsing, conversation state, search, or export behavior.

## Pull-request expectations

Describe the user-facing behavior, include screenshots for UI changes, and keep unrelated formatting changes out of the same pull request. By submitting a contribution, you agree that it may be distributed under the MIT License.
