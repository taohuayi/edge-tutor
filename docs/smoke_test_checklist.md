# Edge Tutor 冒烟测试清单（对齐 Zotero paper-reading-flow）

> 架构：内存会话为主（.conv.json 存 threads+messages+reading），节点 .md 为沉淀镜像。
> 交互全面对齐 Zotero 原版。测试前置：API key 可用（环境变量 EDGE_TUTOR_API_KEY 或设置页）。

## 自动测试（npm test）

纯函数层（canvas/conv/export/guide/tutor）由 `node:test` 覆盖，改这些模块前先跑：

```bash
npm test        # 构建测试 bundle + 跑 33 个用例（零依赖）
```

- 测试文件：`test/*.test.mjs`（import `test/.build/*.cjs`，由 `scripts/build-tests.mjs` 生成）
- 重点回归项：conv 迁移容错（v1-v4）、重建会话的工作区边界（不递归子工作区）、
  导图环检测不死循环、备份 roundtrip、节点 frontmatter 解析
- 新增纯函数逻辑时同步补测试；`npm test` 不通过禁止构建发布

## 环境准备

- [ ] API key 已配置（环境变量或设置页），启动 Obsidian
- [ ] 打开面板（左侧罗盘 / 命令面板「打开认知边缘导师面板」）

## A. 基础

### 1. 追问 + 线程建立
- [ ] 教材选中文本 → 蓝色「由此追问」→ 面板出现新线程 + 消息，AI 回答
- [ ] 面板顶部「当前思维链」区出现：面包屑（线程标题）+ 当前问题
- [ ] 若来自选中文本，显示「由上一段文字引出」原文摘录

### 2. 继续追问
- [ ] 输入框再提问（不点分叉）→ 消息归属同一线程，线程内出现上下文分隔
- [ ] AI 回答后，当前线程的「上次停在：…」摘要更新

### 3. 分叉（branchNext）
- [ ] 点当前思维链区的「从这里分叉」→ 输入框 placeholder 变「输入新分支的起点…」
- [ ] 输入内容发送 → 新建子线程（导图里挂在当前节点下）
- [ ] 消息归属新线程，面包屑变「父 › 子」

### 4. 搁置
- [ ] 点「暂时搁置」→ 当前线程变 paused（导图变暗），活跃线程清空
- [ ] placeholder 变「输入一个新问题，或从思维地图恢复旧分支…」

## B. 视图模式

- [ ] 视图下拉：当前路径 / 全部消息 / 单节点
- [ ] 「当前路径」：只显示活跃线程祖先链上的消息
- [ ] 「全部消息」：显示所有消息
- [ ] 「单节点」：只显示活跃线程的消息

## C. 思维导图

### 5. 布局
- [ ] 线程以纵向树形显示，根节点高亮（active 边框）
- [ ] 活跃线程的祖先链路径连线高亮（active class）
- [ ] 切换活跃线程 → 导图自动滚动定位到该节点

### 6. 节点操作（hover 显示按钮）
- [ ] ➕ 插入子节点 → 新建线程挂在当前节点下
- [ ] ✏️ 改写标题 → 节点显示新标题 + ✏️ 标记（renamed）
- [ ] 📋 复制分支 → 状态栏提示已复制 N 个节点
- [ ] 📌 粘贴 → 在目标节点下复制出整棵子树
- [ ] 📝 改写摘要 → 「上次停在」更新
- [ ] 🗑️ 删除分支 → 确认后线程删除，消息仍保留

### 7. 拖拽重组（Zotero 核心）
- [ ] 拖动节点到另一节点上 → 变为其子节点（落点高亮）
- [ ] 拖到空白 → 回主干（根节点）
- [ ] 拖拽后导图/面包屑/视图随之更新
- [ ] 不能拖到自己子孙下（被拒绝）

### 8. 点击节点
- [ ] 点击节点 → 切换为活跃线程，输入框 placeholder「继续这条思路…」

## D. 消息

### 9. 消息归属与编辑
- [ ] 消息区按线程显示，换线程时出现「线程标题」分隔按钮（点击可跳转）
- [ ] 消息有 ✏️ 编辑按钮 → 内联编辑 textarea + 保存/取消
- [ ] 编辑保存后，原始内容存入 verbatimContent（不丢）

### 10. 停车场
- [ ] 输入框有内容时点「📌 停车场」→ 暂存问题（带当前线程 parentId）
- [ ] 停车场列表点「提问」→ 取出并填入输入框，归属原线程（分支模式）

## E. 沉淀与导出

- [ ] 「💾 沉淀」→ 当前线程生成节点 .md（frontmatter: status/anchor/parent/summary）
- [ ] 「🧭 方向指引」→ 推荐入口以卡片展示
- [ ] 导出当前工作区（Markdown/JSON）内容含真实工作区名
- [ ] 重启 Obsidian → 面板恢复历史消息、线程树、导图、活跃线程

## F. 会话搜索（新增，对齐 Zotero）

- [ ] 工具行搜索框输入关键词 → 搜索计数显示「N 处」/「无匹配」
- [ ] Enter → 逐条跳转命中（Shift+Enter 反向）
- [ ] 命中消息滚动到视野中央
- [ ] 命中线程标题/原文摘录/消息内容（角色标注：线程/原文/追问/回答）
- [ ] 命中线程 → 自动切换活跃线程；无归属消息 → 自动切「全部消息」视图
- [ ] 搜索结果列表点条目 → 跳转对应命中
- [ ] Esc 清空搜索

## G. 导图平移/滚动（新增，对齐 Zotero）

- [ ] 鼠标拖导图空白处 → 画布平移
- [ ] 滚轮在导图上 → 横向滚动（Shift+滚轮）
- [ ] 拖拽时节点不响应（防误触）

## H. 复制带消息 + 粘贴为根（新增）

- [ ] 节点点「📋」复制 → 状态栏提示含消息数
- [ ] 节点「📌」粘贴 → 线程+消息都复制（消息归属新线程 id）
- [ ] 工具行「📌」粘贴为根 → 剪贴板节点成为根节点（含消息）
- [ ] 导出 MD/JSON 按钮在面板工具栏可直接点

## I. 锚点定位（Obsidian markdown 文本锚点适配）

- [ ] 「由此追问」选中文本 → 线程锚点存 `{sourcePath, quote}`
- [ ] 当前思维链区「📍 教材锚点」→ 打开文件 + 定位到引用文本 + 临时选中高亮
- [ ] 消息区 `📖 路径` blockquote 可点击 → 跳回触发问题的原文位置
- [ ] 找不到引用文本时 → 提示「未能在文件中找到锚点文本」（不崩溃）
- [ ] 锚点文件不存在 → 提示（不崩溃）

## K. 宽屏模式（新增）

- [ ] 面板工具行点「⛶」→ 面板移到主编辑区成为独立标签页（全宽）
- [ ] 宽屏下导图/消息区更宽，布局正常
- [ ] 再次点「⛶」→ 回到右侧边栏
- [ ] 切换过程中会话数据不丢（消息/线程/草稿保留）

## L. 思维链质量（新增）

- [ ] AI 回答**流式逐字**出现（非一次性）
- [ ] 流式时若在消息底部 → 自动跟随滚动；若往上滚 → 不打断
- [ ] 回答结束后「当前思维链区」显示最近追问（lastQuestion）+ 上次停在（summary 更新）
- [ ] 分叉后提问 → AI 回复带分支语境（能感知祖先链/断点）
- [ ] 草稿未发送 → 重启恢复文本 + 分叉意图（placeholder 显示"输入新分支的起点…"）
- [ ] 导出 MD → 树形大纲（线程缩进）+ 每条消息（问题N/回答N）+ 停车场
- [ ] 导出 JSON → 完整会话（v4），可再导入

## J. 数据格式

- [ ] `.conv.json` 为 version 4，含 messages（带 lineId）+ reading.threads
- [ ] 旧 v3 格式的 .conv.json 能正常加载（消息保留）

## 已知限制

- `npx tsc` 全量仍有 obsidian.d.ts 自带 HistoryHandler 兼容报错（与插件代码无关）；`src/` 自身 0 错误。
- 只读概念活页（_wiki/concepts/）不再进导图 —— 线程完全来自会话（对齐 Zotero）。
- PDF 框选定位（Zotero 特有能力）在 Obsidian 无法实现，已适配为 **markdown 文本锚点**。
